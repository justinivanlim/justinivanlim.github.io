# Theology 13 Narrative

## Project Overview

This directory inside the `justinivanlim.github.io` repository hosts the GitHub Pages site for the Theology 13 narrative output at `https://justinivanlim.github.io/theo-13-narrative/`. The site is currently in a work-in-progress layout stage using *Lorem ipsum* placeholder text while the final student-authored narrative is being prepared.

## Authorship & AI-Assistance Disclosure

**The narrative content itself is solely authored by the students.** AI tools are used strictly to assist in building and formatting the website, specifically for the HTML and CSS layout structure and communicative framing.

## Repository Structure

```text
theo-13-narrative/
├── index.html   Semantic HTML5 reading layout (work-in-progress placeholder)
├── styles.css   Layered CSS rules, typography scale, light/dark tokens, and print styles
└── README.md    Project documentation and authorship disclosure
```

## Local Preview & Deployment

This is a zero-build static HTML and CSS site with no external dependencies, JavaScript, or bundlers:

- **Local preview:** Open `index.html` directly in a web browser or serve this directory with any static HTTP server (for example, `python3 -m http.server` inside `theo-13-narrative/`).
- **Deployment:** Changes committed and pushed to the `justinivanlim.github.io` repository are published automatically via GitHub Pages.
